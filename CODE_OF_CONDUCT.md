# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

- Be respectful and constructive towards everyone, regardless of background or experience.
- No harassment, insults or personal attacks, in issues, pull requests or any other project channel.
- Criticise code and ideas, not people.
- Maintainers may edit or remove contributions that violate this code and may block people who repeatedly ignore it.

Report problems to the maintainer, [Wolfgang Rabenstein](https://github.com/wolfgangrabenstein), via a GitHub issue or the e-mail address in the GitHub profile.
