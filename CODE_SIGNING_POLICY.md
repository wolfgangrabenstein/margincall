# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).

## What is signed

Only the Windows executable of MARGIN CALL (`MarginCall-<version>-Windows.exe`) is signed. Every signed file is built from the source code in this repository by the public GitHub Actions workflow [`.github/workflows/build.yml`](.github/workflows/build.yml). Nothing built outside this workflow is ever signed. Files from other projects are not signed under this project.

## Build and signing process

1. A release is started by pushing a version tag (`v*`) to this repository.
2. GitHub Actions builds the Windows executable from source (Tauri 2, Rust).
3. The unsigned executable is submitted to SignPath.io through the official GitHub Action.
4. An approver reviews the request and approves it manually in SignPath.
5. The signed executable is attached to the GitHub release.

## Privacy policy / Datenschutz

**English:** This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. In detail:

- **Live market data:** On first start, MARGIN CALL asks whether it may download current market data (Dow Jones, S&P 500, Nasdaq-100, crude oil and a few individual stocks) from Yahoo Finance (`query1.finance.yahoo.com`). Only if the user agrees are these public price data requested. As with any web request, Yahoo receives the user's IP address. No personal data, game data or identifiers are sent. The setting can be changed at any time under *Optionen → Live-Kurse*. Yahoo's privacy policy: <https://legal.yahoo.com/us/en/yahoo/privacy/index.html>
- **Multiplayer (local network):** The game only connects to a multiplayer host that the user picks from the list of games on their own network or whose address they enter. Other players in the same game see the player's in-game name, chosen character and position.
- **Online multiplayer (only after explicit consent):** Online play is off until the user opens *Multiplayer → Online play* and confirms a consent dialog that explains what is transmitted. Only then does the game connect to the MARGIN CALL game server (a Cloudflare Worker with Durable Objects operated by the project, `margincall-highscores.margincall.workers.dev`). The server only forwards the game messages between the players of one game: nickname, game name, chosen character, positions, hits and chat. It does not store game contents. For the list of open games it keeps the game name, host nickname, game mode, number of players and game version while the game is open; the entry is deleted when the host leaves (leftovers are removed after six hours at the latest). Private games are not listed and can only be joined with their code. Other players never see a player's IP address; Cloudflare processes it technically to deliver the connection. The consent can be withdrawn at any time under *Options → Online multiplayer*. Legal basis: consent (Art. 6(1)(a) GDPR).
- **Browser version:** The game can also be played in the browser at <https://wolfgangrabenstein.github.io/margincall/> (GitHub Pages). GitHub receives the visitor's IP address when the page is loaded (<https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement>). In the browser version, live market data (after the same consent as in the app) are fetched through the MARGIN CALL server at Cloudflare instead of directly from Yahoo, so Yahoo does not see the user's IP address. Settings and the local highscore list stay in the browser's local storage.
- **Online leaderboard (only on explicit request):** Nothing is uploaded automatically. After a single-player run the player can enter a name; only if they then press the button labelled "Save & post online" are the self-chosen name, score, level reached, win flag, number of deaths, game mode (normal/hardcore) and game version are sent to the MARGIN CALL leaderboard server (a Cloudflare Worker operated by the project). Each upload therefore requires this explicit action. The option is pre-selected for convenience but can be switched to "local only" per run with TAB or permanently under *Options → Online leaderboard*; ESC skips saving entirely. The leaderboard is only downloaded when the player opens the online tab. The leaderboard is public. Legal basis: legitimate interest in providing a leaderboard (Art. 6(1)(f) GDPR); players may object at any time (Art. 21 GDPR) and request deletion of their entries via a GitHub issue or by contacting the maintainer. IP addresses are not stored; Cloudflare processes them technically to deliver the request. The leaderboard is only downloaded when the player opens the online tab. Cloudflare's privacy policy: <https://www.cloudflare.com/privacypolicy/>
- **Local storage:** Key bindings, settings and the local single-player highscore list (name entered by the player, score, date) are stored locally on the user's computer only and are never transmitted.

**Deutsch:** Dieses Programm überträgt keine Informationen an andere Systeme im Netzwerk, außer der Nutzer verlangt es ausdrücklich. Im Einzelnen:

- **Online-Multiplayer (nur nach ausdrücklicher Zustimmung):** Online-Spielen ist ausgeschaltet, bis der Nutzer *Multiplayer → Online spielen* öffnet und einen Zustimmungsdialog bestätigt, der erklärt, was übertragen wird. Erst dann verbindet sich das Spiel mit dem Spiel-Server von MARGIN CALL (ein vom Projekt betriebener Cloudflare Worker mit Durable Objects, `margincall-highscores.margincall.workers.dev`). Der Server leitet nur die Spielnachrichten zwischen den Spielern einer Partie weiter: Nickname, Spielname, gewählte Figur, Positionen, Treffer und Chat. Spielinhalte speichert er nicht. Die Zustimmung lässt sich jederzeit unter *Optionen → Online-Multiplayer* zurückziehen. Rechtsgrundlage: Einwilligung (Art. 6 Abs. 1 lit. a DSGVO).
- **Browser-Version:** Das Spiel lässt sich auch im Browser unter <https://wolfgangrabenstein.github.io/margincall/> spielen (GitHub Pages). Beim Laden der Seite erhält GitHub die IP-Adresse (<https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement>). In der Browser-Version werden Live-Kurse (nach derselben Zustimmung wie in der App) über den MARGIN-CALL-Server bei Cloudflare statt direkt bei Yahoo abgerufen, Yahoo sieht die IP-Adresse also nicht. Einstellungen und die lokale Highscore-Liste bleiben im lokalen Speicher des Browsers.
- **Online-Rangliste (nur auf ausdrücklichen Wunsch):** Es wird nichts automatisch hochgeladen. Nach einem Einzelspieler-Lauf kann der Spieler einen Namen eingeben; nur wenn er danach den Knopf „Speichern & online stellen“ drückt, werden selbst gewählter Name, Punkte, erreichtes Level, Sieg, Zahl der Tode, Spielmodus (normal/Hardcore) und Spielversion an den Ranglisten-Server von MARGIN CALL gesendet, einen vom Projekt betriebenen Cloudflare Worker. Jeder Upload braucht also diese ausdrückliche Aktion. Die Rangliste wird nur geladen, wenn der Spieler den Online-Reiter öffnet. Die Rangliste ist öffentlich. Rechtsgrundlage: berechtigtes Interesse am Betrieb einer Rangliste (Art. 6 Abs. 1 lit. f DSGVO); Spieler können jederzeit widersprechen (Art. 21 DSGVO) und die Löschung ihrer Einträge über ein GitHub-Issue oder beim Maintainer verlangen. IP-Adressen werden nicht gespeichert; Cloudflare verarbeitet sie technisch bedingt beim Übermitteln. Die Rangliste wird nur geladen, wenn der Spieler den Online-Reiter öffnet. Datenschutzhinweise von Cloudflare: <https://www.cloudflare.com/de-de/privacypolicy/>
- **Lokale Speicherung:** Tastenbelegung, Einstellungen und die lokale Highscore-Liste des Einzelspielers (selbst eingegebener Name, Punkte, Datum) werden nur lokal auf dem eigenen Rechner gespeichert und nie übertragen.

The firmware for the M5Stack Cardputer ADV is not signed by SignPath. It only loads market data after the user has set up WLAN on the device.

## Uninstallation

MARGIN CALL is not installed. To remove it, delete the downloaded file. Settings are kept in the WebView storage of the app and can be reset under *Optionen → Standard wiederherstellen*. The highscore list is the file `MarginCall/highscores.json` in the user's application data folder (Windows: `%APPDATA%`, macOS: `~/Library/Application Support`, Linux: `~/.local/share`); delete it to remove all entries.
